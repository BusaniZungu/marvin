# Pibza Nation Blog

Welcome to **Pibza Nation Blog** — a clean, modern blog website showcasing music, coding journey, and creative thoughts.

---

## Overview

This project is a responsive static blog built with simple HTML, CSS, and JavaScript. It features:

- A professional dark-themed design with a cool blue-green color scheme
- Custom backgrounds on blog posts using CSS variables
- Image-rich posts with overlay effects for readability
- Hover animations including smooth spin and lift effects
- A fixed logo in the header aligned with the blog title and tagline
- Responsive layout that adapts well for smaller screens
